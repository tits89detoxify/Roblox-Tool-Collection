XCutors is designed for Windows 10 and Windows 11 desktop environments.

### Do I need to disable my anticomponent?

Some anticomponent software may flag executor files as false positives. You may need to add exceptions for the XCutors folder to run smoothly.

### Can I add my own executors to the collection?

Yes, the universal loader supports adding custom executors. Please refer to the documentation for configuration steps.

### How do I update the executors?

The universal loader includes an auto-update feature. You can also manually check for updates via the dashboard settings.

### Is this project affiliated with Roblox Corporation?

### Can I use this on macOS or Linux?

Currently, XCutors is built exclusively for Windows desktop. There are no plans for macOS or Linux support at this time.
